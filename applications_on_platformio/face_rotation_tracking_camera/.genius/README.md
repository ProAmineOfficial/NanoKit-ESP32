# Genius Guides

**Developed by Amine Saoud ibn al-Bashir.**

## Current Status

No automatic Genius generator is installed or executed for this application. This directory is reserved for future project-local engineering guides, checklists, summaries, and validation reports.

The authoritative material remains the application `README.md`, node documentation, connection diagrams, source code, and tests.

## Generated Artifact Requirements

Only store a generated artifact here after a real generator has run. Each artifact must identify:

- Generator name and version.
- Exact command used.
- Input files or evidence.
- Generation date and time.
- Validation status and known limitations.

Do not treat this directory as automation by itself.

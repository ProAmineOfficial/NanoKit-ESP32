## Rules for translators

- The English README is authoritative. When the root README changes, update every translation in the same pull request.
- Keep code blocks, the Mermaid diagram, URLs, relative paths, badges, and icons exactly as in the English README; translate prose, headings, table text, and link text.
- Keep `**Developed by Amine Saoud ibn al-Bashir.**` in English: the attribution term in [NOTICE](../../NOTICE) requires it.
- Keep NanoKit pin labels in the form `Pin 36 / GPIO5`; never abbreviate them.
- Arabic and Persian pages are wrapped in `<div dir="rtl">` for right-to-left reading.
- The generated repository tree appears only in the English README; translations link to [REPOSITORY_TREE.md](../../REPOSITORY_TREE.md).
